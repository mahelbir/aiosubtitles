# Subtitle source limits

This page lists the limits each subtitle site sets, and how AIOSubtitles uses them. The figures come from each site's own docs and from the live test runs. A `?` means the site does not document that value.

## Terms

- **Per IP:** the limit is counted against the server's address, so every user of the server shares it.
- **Per key:** the limit is counted against one API key or token, so each user who enters their own key gets their own allowance.
- **Background:** after a subtitle list goes out, the server downloads some files on its own to check them and to compare their timing with a hash-matched subtitle. A timing match marks the row "Exact".

## How the server paces itself

- A download made with the user's own key spends that key's budget when the source declares one.
- Every other download, whether keyless or made with a server key, spends one budget shared by the whole server.
- A 429 or a 503 with `Retry-After` from the site opens a short breaker for the whole source. A per-key limit marks only that key "Limit reached".
- Searches spend no budget. They are cached and shared between users.
